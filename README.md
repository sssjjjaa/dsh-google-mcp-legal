# DSH Google MCP — Privacy Policy & Terms

Last updated: 2026-11-22

This repository hosts the privacy policy and terms of service for **DSH Google MCP**, a
single-user OAuth application used to connect a personal AI assistant (DeepSeek Harness)
to the account owner's own Google Calendar, Gmail, and Google Drive.

Owner: sssjjjaa2026@gmail.com

---

## <a id="privacy"></a>Privacy Policy

**Who this app is for.** DSH Google MCP is a personal, non-commercial tool. It is run
locally by the account owner on the owner's own computer. It is not offered to the public
and has no sign-up.

**What it accesses.** With the owner's explicit consent, the app uses Google OAuth 2.0 to
access:

- Google Calendar — read calendars and events, create and update events
- Gmail — read, draft, send, and label the owner's own messages
- Google Drive — search, read, download, upload, and manage the owner's own files, and
  read/write Google Docs, Sheets, and Slides

It accesses only the account that granted consent.

**Where data goes.** Nowhere else. OAuth access and refresh tokens are stored as plain
files on the owner's local disk.

The app has no backend server. It does not collect analytics, does not log message or file
content to any remote service, and does not sell, rent, or share user data with any third
party.

**Google API Services User Data Policy.** The app's use of information received from Google
APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.

**Revoking access and deleting data.** The owner can revoke access at any time at
<https://myaccount.google.com/connections>, and can delete the local token files.
Revocation takes effect immediately.
